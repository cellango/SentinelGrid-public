# Historical documentation

These documents preserve earlier technical references, operations, and validation
attempts. They are excluded from current navigation authority. Their commands,
API tables, assertions, dates, signoffs, and diagrams may not match the reviewed
source. Start with [current architecture](../architecture/overview.md),
[the documentation index](../README.md), and [release scope](../../RELEASE_SCOPE.md).

- [Earlier validation records](validation/README.md)
- [Earlier operations/runbooks](operations/README.md)
- [Earlier technical references](reference/README.md)

Superseded design drafts, repeated progress reports, duplicated research, and
business documents are not kept in this public archive. Original copies remain
recoverable privately. A historical link to a retired file is identified as such,
not treated as a missing prerequisite for supported source checks. Legacy release
verification scripts may still require retired private artifacts and are not
supported preview entrypoints. No archived signoff can approve a current release.
