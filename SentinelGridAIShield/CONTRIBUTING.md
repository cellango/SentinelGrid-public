# Contributing to AI Shield source

Follow the root [contribution guide](../CONTRIBUTING.md) and preserve this component's
[Apache-2.0 license](LICENSE). Keep gateway, services, and documentation changes
focused, and describe the exact checks run. The monorepo's supported checks and
dependency scope are in the root [README](../README.md).

Component integration tests and standalone Docker/database/provider operations are
experimental references. Their presence does not make them supported preview
commands. Use [private security reporting](SECURITY.md) for vulnerabilities.
